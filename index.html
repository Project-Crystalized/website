Welcome to Crystalized!

  • Our community: We are a community of people originating from a now closed Minecraft server called tubnet.gg. We are a diverse community from all over the world.
  • Minigames: We started out trying to preserve some of tubnet's old games by replicating them, and we have ideas for our own custom games in the near future.
  • Open source: All of our code is open source and available under the GPL license, so you can use it freely, but any changes you make to it must be made open source and available to the public.
  • Cross-platform: We aim for Java and Bedrock compatibility, so Java and Bedrock players can play together in the same games.
  • Multi-language: The server is available in different languages.
