About Us

  • Our community: We are a community of people originating from a now closed Minecraft server called tubnet.gg. We are a diverse community from all over the world.
  • Minigames: We started out trying to preserve some of tubnet's old minigames by remaking them, and we have ideas for our own custom games in the near future.
  • Open source: All of our code is open source and available under the GPL license on GitHub, so you can use it freely, but any changes you make to it must be made open source and available to the public.
  • Cross-platform: We aim for Java and Bedrock compatibility, so Java and Bedrock players can play together in the same games.
  • Multi-language: The server is available in different languages.

Current Status

  • Release: The server is currently under development and hasn't released yet. But we hope to release soon™. Release is roughly targeted for the end of 2026 or early 2027 but that is very much not set in stone.
  • Games: 2 of our 3 games that we planned to take over from tubnet are basically done, and the third one is under heavy development.
  • Original games: Work on an original game from us has started but isn't very far. Multiple ideas for other original games are floating around but haven't been started on yet.
  • Lobby: Our main lobby is under development as well as some maps for our games. We have a temporary lobby tho that is likely to be used on release.
