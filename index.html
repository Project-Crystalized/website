Welcome to Crystalized!

We are a Community of people originating from a former minecraft server, tubnet.gg
We set out to build our own minecraft server, focused on mini games. We started out trying to preserve some of tubnet's old games by replicating them. But we do also have some ideas for our own custom games in the near future.
All of our code is open source, and available under the GPL license, that means you can use our code freely, but changes that you make to it, will have to be made open source and available to the public.
We try to achieve java and bedrock compatibility, so java and bedrock players can play together in the same games.
The server is avaialable in different languages.
